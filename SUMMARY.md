## ⚙️ Customization Quick Tips

### Change Your Name
Edit in `index.html`:
```html
<h1>Your Name <span>Here</span></h1>
```

### Update Skills
Add/remove skill cards in the skills section

### Modify Projects
Edit project titles, descriptions, and technologies directly in HTML

### Change Colors
Update CSS variables in `style.css`:
```css
--primary-color: #ff3e3e;    /* Main color */
--bg-color: #121212;         /* Background */
--text-color: #e0e0e0;       /* Text */
```

### Add More Projects
Duplicate a project card in `projects.html` and update:
- Title and subtitle
- Technologies
- Features and learning outcomes
- Links to demos and source code
